# 01 — Project Scope

## Product Name
Aureum Sales CRM

## Brand
Aureum Mall & Residences

## Product Type
Custom real-estate sales CRM / sales operations system.

## Main Objective
Create a centralized CRM where the sales team can manage leads, customers, follow-ups, agent activity, internal communication, reports, and system settings based on user role.

## Core Sales Flow
Lead → Customer → Follow-up → Communication → Negotiation → Booking → Closed Deal

## Phase 1 Screens
1. Login Screen
2. Dashboard Screen
3. All Leads Screen
4. My Leads Screen
5. Add New Lead Screen
6. Customers Screen
7. Customer Detail Drawer
8. Follow-ups Screen
9. Internal Team Chat Screen
10. Agent-wise Reports Screen
11. Agents Management Screen
12. Settings Screen

## Phase 1 Users
1. Super Admin
2. Sales Manager
3. Sales Agent

## Phase 1 Modules

### Authentication
- Login
- Role detection
- Role-based dashboard redirect
- Protected routes

### Leads
- All Leads
- My Leads
- Add New Lead for Sales Manager
- Lead status management
- Lead assignment
- Lead notes
- Lead filters

### Customers
- Customer list
- Customer profile drawer
- Contact details
- Interest details
- Activity timeline
- Notes
- Follow-up history

### Follow-ups
- Today’s follow-ups
- Overdue follow-ups
- Upcoming follow-ups
- Completed follow-ups
- Missed follow-ups
- Rescheduled follow-ups
- Calendar/date filters
- Follow-up detail drawer

### Team Chat
- Internal channels
- Direct messages
- Text messages
- File attachments
- Unread count
- Message time
- Online/offline status

### Reports
- Agent-wise performance
- Lead activity
- Follow-up performance
- Closed deals
- Conversion rate
- Agent detail drawer

### Agents
- Agent list
- Add/edit agent
- Assign team
- View agent activity
- Activate/deactivate agent

### Settings
- Super Admin only
- Company settings
- Role and permission settings
- Lead statuses/tags
- Lead sources
- Notification settings
- CRM preferences

## Excluded From Phase 1
Do not implement these modules in Phase 1:
- Projects Screen
- Properties / Units Screen
- Visits Screen
- Tasks Screen
- Meetings Screen
- Full complex opportunity pipeline
- Accounting module
- HR/payroll module
- Public website pages

## Main Business Outcome
After Phase 1, the team should be able to:
- Login by role
- See role-based sidebar
- Manage leads
- Track customers
- Create and complete follow-ups
- Use internal team chat
- Review reports
- Manage agents
- Configure CRM settings through Super Admin
